# Invariants the fix pass must not weaken

1. Original user question is immutable.
2. A semantic research-state change has a new revision/identity.
3. No model output grants network/tool/publication/privacy authority.
4. Unknown provider outcome/cost never causes blind retry.
5. A paid attempt is issued at most once per exact durable attempt identity.
6. Stale worker/lease cannot write private content.
7. Deleted account/source cannot be resurrected by late callbacks.
8. Evidence citations resolve to owned exact stored passages.
9. A model cannot invent evidence handles.
10. Missing assessment is not support.
11. Missing coverage review is not coverage.
12. "Not found" is not proof of absence.
13. Unknown freshness is not fresh when freshness is required.
14. Syndicated copies do not become independent confirmations.
15. Private-derived query terms never leave the boundary without exact authority.
16. Search/source text is untrusted data, not instructions.
17. Correction reuses evidence, never stale conclusions by assumption.
18. `completed` means complete structured coverage.
19. `completed_with_limitations` still requires machine-verifiable disclosure of every blocking unresolved item.
20. Fixture/native/unit evidence is never relabeled live semantic evidence.
21. The acceptance matrix cannot PASS a capability merely because a helper exists.
22. No test timeout/assertion is weakened without root-cause evidence.
