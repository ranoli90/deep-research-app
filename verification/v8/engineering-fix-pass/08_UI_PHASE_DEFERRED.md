Do **not** let the engineering fix pass become another visual redesign.

Defer:
- Reanimated/Skia visual signature
- icon system replacement
- haptic polish
- typography system
- Settings visual redesign
- Library visual redesign
- research trace animation language
- evidence-sheet visual craft
- composer shape/color polish
- report editorial visual system
- competitive screenshot recreation

But fix now if functional:
- IME send occlusion
- wrong/stale UI state
- privacy/activity contract
- query approval stuck state
- assumption/steering revision truth
- long-report correctness/performance gate measurement
- accessibility semantics caused by functional state.

After engineering is stable, perform the dedicated Product Experience/UI phase against the user-supplied Grok/Perplexity/DeepSeek recordings.
