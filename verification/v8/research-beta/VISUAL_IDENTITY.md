# Deep visual identity (original)

Not a Grok/ChatGPT/Perplexity clone.

## Competitor reference (principles only)

Grok: empty first canvas, compact bottom composer, collapsible thinking, minimal chrome.
DeepSeek: automatic collapse of reasoning, readable tables, simple input.
ChatGPT Deep Research: plan + live progress + steer + TOC + sources used.
Perplexity: + attach, numbered citations, library history, quiet navigation.

Ours differs: warm paper/ink/teal, quote-first evidence sheet with Technical Details, semantic public activity pulse (not CoT), assumption confirmation as a real mutation.
