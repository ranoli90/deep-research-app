# Bounded whole-passage evidence selection

Requirements W01/W02/W03/W05/W06/W08; base `3f22f5b3cd96b85fc78c1843fc9feb1bcb367562`. Implementation and verification in progress. Canonical behavior is in ENGINE_CONTRACTS and ADR055; this is the change/impact packet.

User outcome: large documents can yield a cited, explicitly partial assessment without clipping passage text or raising spending/context limits. Selection ranks evidence for inspection; it does not establish support, completeness, eligibility, or absence of counterevidence. Neighbor inclusion does not establish distant footnote/cross-reference completeness. Semantic quality and live superiority remain unproven.

Impact checklist: new pure research-core policy and backend-owned `evidence_selections` inventory; additive migration038 adds immutable metadata/proof and opaque run obligations plus a per-run policy. No dependency, service, vendor SDK, public action/API schema, provider route, output contract, prompt text, monetary allowance or processor change. Internal model context adds strictly validated optional selection metadata and input-manifest.v5; all prior manifest readers remain. The request digest includes the new context. Existing runs retain legacy-all.v1, including issued/unknown logical actions; only new admissions default to whole-passage-selection.v1. Snapshot corrections are new runs, with fresh selection over authorized reused membership. Tables/metadata follow account and source deletion. Raw text is not duplicated into the inventory.

Atomicity: creation/replay occurs in the existing account/run/lease-fenced worker transaction. Obligation identity and proof commit together; no network I/O. Concurrent callers serialize under the existing locks. Exact candidates (including omissions), source versions, locators, titles, digests, original question digest, required target quotes, evidence revision and policy bind the proof. An original proof restores its own inventory after evidence is added; current-context validation rejects stale revisions. Missing/corrupt proof blocks publication and deterministically terminalizes the worker without reissuing a model action. PostgreSQL/transient/lease errors retain their existing handling.

Tests: pure determinism/late evidence/renamed entities/contradiction/neighbor and escaped UTF8 budget controls; real PostgreSQL concurrent replay, revision/owner isolation, corruption, mandatory omission warning, source/account deletion; production worker bounded original/replay/correction and unchanged direct count/byte issuance limits. Supplied official documents remain distinct from synthetic/fabricated semantic controls. Exact results and failed attempts belong to `verification/v6/evidence-selection/`.

Rollback: stop new selection-enabled admissions/dispatch if needed. Retain migration038, policy/proof/obligation readers, legacy request identities, publication limitations and vetoes, account/source deletion and unknown financial holds. Never flip an admitted run to legacy to remove obligations, discard inventory to retry, or erase already issued action identity. No cloud migration/deployment is authorized by this packet.
