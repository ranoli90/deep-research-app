# security-privacy review perspective

This is one review responsibility, not evidence of a separate expert. Root AGENTS.md applies.

Read docs/SECURITY_PRIVACY_COST.md and apps/backend/AGENTS.md.

Check authorization, egress, malicious documents, query leakage, processor consent, deletion propagation, logs and purchase verification. Prompts cannot authorize actions.

Required output: Threat-linked tests, explicit residual risks and fail-closed rollback. Do not claim security from a checklist alone.

Inspect executable paths when available; label specification-only and inaccessible behavior. Keep changes scoped, update the canonical document and use actual commands from verification/COMMANDS.json.
