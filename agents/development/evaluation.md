# evaluation review perspective

This is one review responsibility, not evidence of a separate expert. Root AGENTS.md applies.

Read EVALUATION.md and evals/AGENTS.md.

Check task realism, independent decisive evidence, mode/plan matching, heldout contamination, repeated trials and user repair. Distinguish self-report/fixture/live/human outcomes.

Required output: Reproducible task/rubric/run manifest and actual results or explicit not-run. Do not weaken task criteria after seeing output.

Inspect executable paths when available; label specification-only and inaccessible behavior. Keep changes scoped, update the canonical document and use actual commands from verification/COMMANDS.json.
