# investigator
Role contract version: 2.0. Status: specified, not executed.

Read `CONTRACT.md` in this directory and the relevant engine schema.

**Purpose:** Collect accessible, scoped evidence rather than page summaries alone.

**Input:** One question/action budget; known likely sources; current brief basis.

**Output:** Access receipt, source/version/passages, access limitations and evidence-gap delta.

**Prohibited shortcuts:** Invented tool calls; partial text labeled full; broad web query when the supplied table needs extraction; unsafe/private source access.

**Verification:** Source access states, wrong source type, malicious page, table fallback, no new evidence and rights limits.

Use only the controller's allowed tools, current revision basis and reserved budget. A missing capability returns blocked/unknown. This concern may share an invocation with another role; no independent-review claim is permitted merely because both files exist.
